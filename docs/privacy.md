## PRIVACY

This Seven Goes to Eleven sends one anonymous ping per day — app version and
country, derived from your IP by the server and never stored. No identifier, no
patch data, nothing about your Seven, nothing that could identify you. Turn it
off under Help ▸ Send anonymous daily ping. The code is in
[`relay/worker.js`](https://github.com/danielspils/this-seven-goes-to-eleven/blob/main/relay/worker.js)
if you'd like to check.

Why? It helps me see where the app is being used and which versions people are
actually running. It's the Scoobie Snack I enjoy for writing and releasing this
free app. Thanks!

This site counts page views and download-button presses with
[GoatCounter](https://thissevengoestoeleven.goatcounter.com) — no cookies,
nothing to consent to.
